# Note explicative — utilisation de l'intelligence artificielle

## Contexte du projet

Le site « Les Courants de la Baie » est un concept pédagogique fictif d'événement de natation en eau libre imaginé sur la côte basque, dans le cadre d'un projet de site web statique en M2 STAPS MOS. La manifestation, sa date, ses formats, ses horaires et son organisation ne sont pas réels ni confirmés.

## Outils d'intelligence artificielle utilisés

- **ChatGPT (OpenAI)** : exploration du concept événementiel, structuration du contenu des cinq pages, rédaction de premières versions de textes et production du code HTML, CSS et JavaScript.
- **Outil de génération d'images de ChatGPT** : création des trois visuels originaux intégrés localement dans `images/`.

Les textes, les images générées, la structure et le code ont été préparés avec assistance d'IA. Le formulaire est une simulation front-end : il ne transmet ni n'enregistre de données.

## Personnalisation déjà intégrée

À partir des informations fournies par l'étudiant, la page d'accueil a été personnalisée avec :
- Nom : Enguerrand Gonzaga.
- Âge : 24 ans.
- Formation : Master 2 STAPS MOS.
- Université : Université Paris Nanterre.

Le texte de présentation relie ces informations au projet fictif de nage en eau libre. Les autres éléments biographiques non fournis n'ont pas été inventés.

## Transparence sur les visuels

Les trois visuels fournis sont des images originales générées par IA, non des photographies de l'événement ou des photographies stock issues de Pexels/Unsplash. Si le cours exige strictement des photographies issues d'une banque d'images avec une licence explicite, remplacer ces fichiers par des photos sélectionnées sur une banque autorisée et compléter `SOURCES_IMAGES.md` avec l'auteur, la page source et la licence vérifiée.
